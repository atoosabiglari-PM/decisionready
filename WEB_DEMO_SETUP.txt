DecisionReady Web Demo Bundle

Files:
- webapp.py
- apprunner.yaml
- pyproject.toml

After uploading this ZIP to AWS CloudShell:

1. From the decisionready repo:
   unzip -o ~/decisionready-web-demo.zip -d .

2. Install/update dependencies:
   pip install -e .

3. Verify existing tests:
   pytest -q

4. Commit and push:
   git add webapp.py apprunner.yaml pyproject.toml
   git commit -m "Add public DecisionReady web demo"
   git push origin main

Then create an AWS App Runner service from the public GitHub repository.
