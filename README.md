# DecisionReady

**Autonomous Change Impact & Decision Readiness for Complex Programs**

DecisionReady helps program leaders determine whether a proposed project change is actually ready for a human decision.

## What DecisionReady Does

- Detects changes against an approved baseline
- Traces the change blast radius across project domains
- Derives required evidence and approvals
- Evaluates READY, NOT_READY, or BLOCKED status
- Builds Change Impact and Decision Readiness graphs
- Keeps consequential decisions human-controlled
- Promotes approved changes into versioned baselines
- Records an auditable change log and status report

## Core Principle

Most AI assistants give leaders more information. DecisionReady determines whether there is enough information to make a decision at all.

## Lifecycle

Baseline → Change Detected → Impact Analysis → Impact Graph → Governance Analysis → Decision Readiness → Human Decision → New Baseline → Change Log

## Demo

The first executable scenario models a product launch expanding from the United States to Germany.

Additional scenarios will cover cloud migration, ERP transformation, and M&A integration.
